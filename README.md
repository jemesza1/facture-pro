# FacturePro SaaS — Bilingual Invoice Generator (AR / FR)

**Client-side only.** All invoice data stays in the user's browser (`localStorage`).
Nothing is stored on any server.

## Features
- Split-screen: form + live A4 preview
- Bilingual French / Arabic with full RTL
- Inter (FR) + Cairo (AR)
- Logo drag-and-drop
- Dynamic lines + TVA + discount
- PDF + Print A4
- Privacy footer

## Setup
```bash
npm install
npm run dev
```

## Privacy
Your data is processed locally in your browser and is never stored on our servers.
